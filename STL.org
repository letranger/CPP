https://hackmd.io/@sa072686/20TT_STL

* 比賽時間估算
** 先計算 O(N)，再看題目給的 N 範圍，例如：
complexity 為 \(N^2\) ，\(1 \le N \le 3000\) ，則最糟的狀況為 \(3000^2=9 \times 10^6\)
現代評測機每秒約可執行 \(10^7 \sim 10^8\) 次簡單運算（視運算內容與常數而定），概略準則：
- < \(10^7\) : 一定會過
- \(10^7 \sim 10^8\) : 應該會過
- \(10^8 \sim 5 \times 10^8\) : 有機會，取決於常數與評測機速度
- > \(10^9\) : 幾乎不可能過
** 反向推論，也可以由 N 的範圍來回推應該要寫出 \(O(N^2)\) 或是 \(O(N)\) 的解決

* vector
預設為空的，可視為隨時可改變大小的陣列
常用來解決 graph 的問題

vector 容量不足時會以倍數擴容（倍率由實作決定，常見 1.5~2 倍），使 push_back 攤銷 O(1)

* vector 少用的 operator: find, insert, erase
這些動作都會讓 vector 去逐一改變所有元素的位置，速度會很慢，複雜度為 O(N)
例如，若有某題要求做刪除 vector 中的 N 個元素，其複雜度就會變成 \(O(N^2)\)
比較好的做法是：開一個新的 vector，再逐一把需要的元素放到新的 vector 中
find 也是 O(N)，如果只是要找一次，可以自己寫 for；如果要找很多次，可以先 SORT 再用 binary_search 或 lower_bound（見後）

* SORT
intro sort: \(O(n \log n)\) ，quick sort+某些功能，使其最差狀況不那麼差
預設由小排到大
sort(ary, ary+n); // [0, n) 左閉右開
- 需要自訂順序時，建議另外寫一個 comp 函式（或 lambda）傳給 sort，而不是去重載自訂型別的 operator<
sort(ary, ary+n, comp);
** comp
comp 可以是一般函式，也可以是 C++11 的 lambda（見下一節）
- example
#+begin_src cpp :eval no
// 由大排到小
bool comp(int p, int q) {
    if (p > q)
        return true;
    return false;
}
// 在 main() 中：
sort(v.begin(), v.end(), comp);
#+end_src
function comp 的撰寫要非常小心，要保證 p,q 兩者反過來後絕對不會 return true（術語叫 strict weak ordering），否則 SORT 會出現 run time error，典型的例子是:
#+begin_src cpp :eval no
// 由大排到小
bool comp(int p, int q) {
    if (p >= q) // p, q對調後有可能也成立
        return true;
    return false;
}
// 在 main() 中：
sort(v.begin(), v.end(), comp);
#+end_src
** lambda 寫法
C++11 起可以把 comp 直接寫在 sort 裡面，不用另外命名一個函式，競程很常用：
#+begin_src cpp -r -n :results output :exports both
#include <vector>
#include <algorithm>
#include <iostream>
using namespace std;
int main() {
    vector<int> v = {3, 7, 1, 9, 4};
    sort(v.begin(), v.end(), [](int a, int b) { return a > b; });  // 由大排到小
    for (auto x : v)
        cout << x << " ";
    cout << endl;
}
#+end_src

: 9 7 4 3 1
** stable / unstable
sort 本身為 unstable，若需要 stable 則可 stable_sort()
** 對一份 ary 做不同版本的 sort
| 陣列    | 0 | 1 | 2 | 3 | 4 |
|---------+---+---+---+---+---|
| A       | 3 | 7 | 5 | 6 | 4 |
|---------+---+---+---+---+---|
| P(原始) | 0 | 1 | 2 | 3 | 4 |
| P(排序) | 0 | 4 | 2 | 3 | 1 |
|---------+---+---+---+---+---|
如此就可以有很多種 P，可以進行不同的 sort，如由大到小、由小到大.....
此時的 comp 要寫為:
#+begin_src cpp :eval no
bool comp(int p, int q) {
    if (A[p] < A[q])
        return true;
    return false;
}
#+end_src
若 A 的原始順序為排隊的先後，A的元素代表等級，如果讓等級高的人先得到服務，等級一樣的人則依排隊順序，則其 comp 寫法為：
#+begin_src cpp :eval no
bool comp(int p, int q) {
    if (A[p] != A[q])
        return A[p] > A[q];
    return p < q;
}
#+end_src

* lower_bound
** 寫法
lower_bound(ary, ary+n, k): 以 binary search 找到第一個>=k 的元素
用在 vector 上則寫 lower_bound(v.begin(), v.end(), k)
** 先決條件
- 要有 operator<
- 要能 random access，使其複雜度為 \(\log_2 n\)
- partitioned by k: 要能找到一個 i，可以把 ary 分切成兩半(即 sorted)
  即，存在 i, \(0 \le i < n\) ，對 j<i 可找到 ary[j]<k，對 j>=i，可找到 ary[j]>=k
** 注意：
lower_bound 只需要資料已排序即可使用，與數值範圍大小無關；「數字範圍很大（如 \(10^9\) ）會超時」指的是開一個以數值當索引的桶陣列（值域陣列）的做法，那是桶陣列的限制，不是 lower_bound 的限制

* upper_bound
upper_bound(ary, ary+n, k): 以 binary search 找到第一個 >k 的元素（lower_bound 是 >=k，upper_bound 是 >k）
兩者相減就是 k 在已排序陣列中出現的次數，這是最經典的搭配用法：
#+begin_src cpp -r -n :results output :exports both
#include <algorithm>
#include <iostream>
using namespace std;
int main() {
    int ary[] = {1, 3, 3, 3, 5, 7};
    int n = 6, k = 3;
    cout << lower_bound(ary, ary+n, k) - ary << endl;  // 第一個 >=3 的位置
    cout << upper_bound(ary, ary+n, k) - ary << endl;  // 第一個 >3 的位置
    cout << upper_bound(ary, ary+n, k) - lower_bound(ary, ary+n, k) << endl;  // 3 出現的次數
}
#+end_src

回傳的是 iterator（指標），減去起點 ary（或 v.begin()）才是索引值

* algorithm 常用函式
除了 sort 和 lower_bound/upper_bound，algorithm（及 numeric）還有一些比賽常用的函式：
| 函式                          | 功能               | 複雜度   | 標頭      |
|-------------------------------+--------------------+----------+-----------|
| max_element(b, e)             | 回傳最大值的位置   | O(N)     | algorithm |
| min_element(b, e)             | 回傳最小值的位置   | O(N)     | algorithm |
| count(b, e, k)                | k 出現幾次         | O(N)     | algorithm |
| reverse(b, e)                 | 反轉               | O(N)     | algorithm |
| swap(a, b)                    | 交換兩個變數       | O(1)     | algorithm |
| binary_search(b, e, k)        | k 是否存在(需排序) | O(log N) | algorithm |
| accumulate(b, e, 初值)        | 總和               | O(N)     | numeric   |
b, e 分別代表起點與終點（如 v.begin(), v.end() 或 ary, ary+n）
注意 max_element/min_element 回傳的是 iterator，要取值記得加 =*=
#+begin_src cpp -r -n :results output :exports both
#include <algorithm>
#include <numeric>
#include <vector>
#include <iostream>
using namespace std;
int main() {
    vector<int> v = {3, 7, 1, 9, 4};
    cout << *max_element(v.begin(), v.end()) << endl;
    cout << *min_element(v.begin(), v.end()) << endl;
    cout << count(v.begin(), v.end(), 7) << endl;
    cout << accumulate(v.begin(), v.end(), 0) << endl;
    reverse(v.begin(), v.end());
    for (auto x : v) cout << x << " ";
    cout << endl;
}

* map
mapping 之意，功能類似 python 的 dict，但底層不同：map 是紅黑樹，任何查詢刪除時間為 O(log n)，且常數因子較大（python 的 dict 是雜湊表，比較接近後面介紹的 unordered_map）
因為是紅黑樹，所以其實 map 隨時都在依 key 排序

* stack 與 queue
AdvanceC++ 教材中示範過用陣列手刻 stack/queue，STL 已內建現成的：
- stack：後進先出（LIFO），=push()= / =top()= / =pop()= / =empty()=
- queue：先進先出（FIFO），=push()= / =front()= / =pop()= / =empty()=
#+begin_src cpp -r -n :results output :exports both
#include <stack>
#include <queue>
#include <iostream>
using namespace std;
int main() {
    stack<int> st;
    st.push(1); st.push(2); st.push(3);
    while (!st.empty()) { cout << st.top() << " "; st.pop(); }
    cout << endl;
    queue<int> qu;
    qu.push(1); qu.push(2); qu.push(3);
    while (!qu.empty()) { cout << qu.front() << " "; qu.pop(); }
    cout << endl;
}
#+end_src

#+RESULTS:
: 3 2 1
: 1 2 3
注意 =pop()= 只移除元素、不回傳值，要先用 =top()= / =front()= 取值再 pop

* priority_queue
底層實作為 heap，適合只關心極端值（最大/最小）的應用
push 和 pop 都是 O(log n)，top 是 O(1)
** 用法
預設是 max-heap（top 是最大值）；要 min-heap 則多給兩個 template 參數：
#+begin_src cpp -r -n :results output :exports both
#include <queue>
#include <iostream>
using namespace std;
int main() {
    priority_queue<int> pq;  // max-heap，top 是最大值
    pq.push(5); pq.push(1); pq.push(8);
    while (!pq.empty()) { cout << pq.top() << " "; pq.pop(); }
    cout << endl;
    priority_queue<int, vector<int>, greater<int>> minpq;  // min-heap，top 是最小值
    minpq.push(5); minpq.push(1); minpq.push(8);
    while (!minpq.empty()) { cout << minpq.top() << " "; minpq.pop(); }
    cout << endl;
}
#+end_src

#+RESULTS:
: 8 5 1
: 1 5 8
** 使用時機
最短路徑（Dijkstra）都會用到：每次要取出「目前距離最小」的點，用 priority_queue 可以把 \(O(V^2)\) 的作法降到 \(O(E \log V)\) ；若改用雙層 for 逐一找最小值，資料一大就會 TLE
