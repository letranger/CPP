1.1.2. 程式要求說明

  1. 背景故事

    農夫老王發現兔子們偷菜的行動會受到天氣變化的影響，天氣狀況以整數代碼表示。學生們需要幫助農夫計算每次偷菜所造成的蔬菜損失。

    每次偷菜的效率由兔子的「飢餓值」 `h`、偷菜次數 `t` 和天氣狀況 `w`（整數）決定：

    • 當 `w = 1` 代表「晴天」，且 `h > 5`，兔子的偷菜效率會提升，損失點數為：
      • 第 `i` 次偷菜的損失點數為：`h * (i + h)3` 顆蔬菜。
    • 當 `w = 2` 代表「下雨天」，且 `h <= 5`，兔子會選擇休息，當次偷菜不造成任何損失。
    • 其他情況下，損失點數為：
      • 第 `i` 次偷菜的損失點數為：`h * (i + h)2` 顆蔬菜。
  2. 輸入
    • 讀入兔子的飢餓值 `h`、偷菜次數 `t`，以及天氣狀況 `w`（1 代表晴天，2 代表下雨天，3 代表陰天）。
  3. 輸出
    • 輸出每次偷菜所造成的蔬菜損失或休息狀況。
  4. 解答
    #include <iostream>

using namespace std;

int main() {
    int h, t, w;

    cout << "Enter hunger level (h), number of heists (t), and weather condition (w): ";
    cin >> h >> t >> w;

    for (int i = 1; i <= t; i++) {
        if (w == 1 && h > 5) {
            long long loss = h * (i + h) * (i + h) * (i + h);
            cout << "Heist " << i << " caused a loss of: " << loss << " vegetables" << endl;
        } else if (w == 2 && h <= 5) {
            cout << "Heist " << i << ": Rabbit chose to rest, no vegetables lost." << endl;
        } else {
            long long loss = h * (i + h) * (i + h);
            cout << "Heist " << i << " caused a loss of: " << loss << " vegetables" << endl;
        }
    }

    return 0;
}
  5. 測試資料

    1. **輸入**：`h = 6, t = 3, w = 1` **輸出**：

   Heist 2 caused a loss of: 3888 vegetables
   Heist 3 caused a loss of: 6318 vegetables

    2. **輸入**：`h = 4, t = 3, w = 2` **輸出**： 

         Heist 1: Rabbit chose to rest, no vegetables lost.
   Heist 2: Rabbit chose to rest, no vegetables lost.
   Heist 3: Rabbit chose to rest, no vegetables lost.

    3. **輸入**：`h = 3, t = 2, w = 3` **輸出**： 

         Heist 1 caused a loss of: 108 vegetables
   Heist 2 caused a loss of: 180 vegetables

    4. **輸入**：`h = 5, t = 4, w = 2` **輸出**： 

         Heist 1: Rabbit chose to rest, no vegetables lost.
   Heist 2: Rabbit chose to rest, no vegetables lost.
   Heist 3: Rabbit chose to rest, no vegetables lost.
   Heist 4: Rabbit chose to rest, no vegetables lost.

    5. **輸入**：`h = 7, t = 3, w = 1` **輸出**： 

         Heist 1 caused a loss of: 3375 vegetables
   Heist 2 caused a loss of: 5488 vegetables
   Heist 3 caused a loss of: 8000 vegetables

    ```

1.2.5. 程式要求說明

  1. 背景故事

    在未來的宇宙探索中，星際探險隊需要穿梭於不同星系，為能源匱乏的地球尋找新的能量源。每位探險員擁有自己的能量收集裝置，這些裝置的能量收集效率取決於探險員的「探索值」 `e` 和當地的星系環境 `g`。星系環境以整數代碼表示，每次收集任務的能量收集量也會隨探索次數增加而變化。

    每次能量收集任務的效率由探險員的探索值 `e`、任務次數 `c` 以及星系環境 `g`（整數）決定：

    • 當 `g = 1` 代表「超新星爆發」，且 `e > 7`，能量收集效率將極大增強，收集量為：
      • 第 `i` 次收集的能量量為：`e * (i + e)3` 單位。
    • 當 `g = 2` 代表「黑洞」，且 `e <= 4`，探險員將選擇停止收集以避免危險，此次收集不會產生任何能量。
    • 其他情況下，能量收集量為：
      • 第 `i` 次收集的能量量為：`e * (i + e)2` 單位。
  2. 輸入
    • 讀入探險員的探索值 `e`、收集次數 `c`，以及星系環境 `g`（1 代表超新星爆發，2 代表黑洞，3 代表普通星系）。
  3. 輸出
    • 輸出每次能量收集的量或停止收集的狀況。
  4. 解答
    #include <iostream>

using namespace std;

int main() {
    int e, c, g;

    cout << "Enter explorer value (e), number of collections (c), and galaxy environment (g): ";
    cin >> e >> c >> g;

    for (int i = 1; i <= c; i++) {
        if (g == 1 && e > 7) {
            long long energy = e * (i + e) * (i + e) * (i + e);
            cout << "Collection " << i << " gathered: " << energy << " energy units" << endl;
        } else if (g == 2 && e <= 4) {
            cout << "Collection " << i << ": Explorer chose to stop collecting, no energy gathered." << endl;
        } else {
            long long energy = e * (i + e) * (i + e);
            cout << "Collection " << i << " gathered: " << energy << " energy units" << endl;
        }
    }

    return 0;
}
  5. 測試資料

    1. **輸入**：`e = 8, c = 3, g = 1` **輸出**： 

         Collection 1 gathered: 4096 energy units
   Collection 2 gathered: 5832 energy units
   Collection 3 gathered: 8000 energy units

    2. **輸入**：`e = 3, c = 2, g = 2` **輸出**： 

         Collection 1: Explorer chose to stop collecting, no energy gathered.
   Collection 2: Explorer chose to stop collecting, no energy gathered.

    3. **輸入**：`e = 5, c = 4, g = 1` **輸出**： 

         Collection 1 gathered: 500 energy units
   Collection 2 gathered: 864 energy units
   Collection 3 gathered: 1378 energy units
   Collection 4 gathered: 1944 energy units

    4. **輸入**：`e = 9, c = 2, g = 1` **輸出**： 

         Collection 1 gathered: 5832 energy units
   Collection 2 gathered: 9261 energy units

    5. **輸入**：`e = 4, c = 3, g = 2` **輸出**： 

         Collection 1: Explorer chose to stop collecting, no energy gathered.
   Collection 2: Explorer chose to stop collecting, no energy gathered.
   Collection 3: Explorer chose to stop collecting, no energy gathered.

    ```

    這樣的版本使用了整數代碼來代表星系環境，並將題目描述和測試資料一併做了調整，使得題目更適合沒有學過字串的學生。希望這些修改符合您的需求！
